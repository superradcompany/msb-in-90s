**msb in 90s** is a series of short videos about [microsandbox](https://github.com/superradcompany/microsandbox), one feature per episode. This repo has the code behind each one: a walkthrough you can follow in a minute, the same thing from TypeScript and Python, and a script that measures what the video shows.

##

- <img height="14" src="https://octicons-col.vercel.app/play/A770EF"> **[1. Pause and Resume](01-pause-and-resume)**: Freeze a running sandbox in milliseconds and pick it up exactly where it stopped.
